## What you can explore

- Function declarations and arrow expressions.
- Parameters, return values and concise syntax.

> **Project notes:** This source is a notebook of alternative snippets, with duplicate declarations, unquoted sample output and JSX. It does not run as one Node.js script; copy one valid JavaScript example into a scratch file or REPL at a time.

## Getting started

Use Node.js to explore the examples. No npm packages are required.

```bash
git clone https://github.com/SamOBrienOlinger/Sams-arrow-functions.git
cd Sams-arrow-functions
```

Read [arrow-functions.js](arrow-functions.js) one example at a time. Start a Node.js REPL with `node`, then try:

```javascript
const add = (a, b) => a + b;
add(3, 3); // 6
```
